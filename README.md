# slonb0t

Twitch-бот для канала JesusAVGN. Совмещает развлекательные команды в чате с ведением статистики стримов и поиском клипов через Twitch API.

Авторы: @Danantur, @mooncat3

## Возможности

- Команды для чата: анекдоты, гороскоп, случайные фразы, таймауты и другие развлекательные функции
- Статистика стримов: запись и отображение длительности, категорий, среднего числа зрителей
- Поиск топовых и случайных клипов за заданный период или категорию игры
- Настройки режима работы бота (порог нормы, задержка буфера, режим эмодзи и др.) через команды в чате
- Защита от спама через буфер сообщений и систему таймаутов

## Стек

- Python 3
- [twitchio](https://github.com/TwitchIO/TwitchIO) — подключение к Twitch IRC
- Twitch Helix API — получение клипов и данных канала
- Pastebin API — публикация длинных ответов
- Heroku — хостинг бота

## Структура

| Файл | Назначение |
|---|---|
| `main.py` | Точка входа, инициализация бота |
| `CommandBot.py` | Все команды чата |
| `ChatBot.py` | Логика авто-ответов |
| `AdditionalMethods.py` | Вспомогательные функции (клипы, гороскоп, буфер) |
| `BufferCleaner.py` | Фоновый поток очистки буфера сообщений |
| `CheckingStreamThread.py` | Фоновый поток мониторинга стрима |
| `Settings.py` | Чтение и запись настроек из `data/settings.txt` |
| `config.py` | Параметры подключения (читаются из `.env`) |
| `entertain_functions.py` | Развлекательные функции |

## Запуск

1. Скопируйте `.env.example` в `.env` и заполните значения:

```
cp .env.example .env
```

2. Установите зависимости:

```
pip install -r requirements.txt
```

3. Запустите бота:

```
python main.py
```

## Переменные окружения

См. файл `.env.example` в корне репозитория.
